遇到同步、共享或快捷记账问题时，可以先查看下面的处理方法，或直接联系我们。

iCloud 数据没有同步

  1. 确认设备登录的是同一个 Apple 账户，并已开启 iCloud Drive；
  2. 在系统“设置 → Apple 账户 → iCloud”中确认攒记可以使用 iCloud；
  3. 保持网络连接，在记账本或攒目标页面下拉刷新；
  4. 首次同步或数据较多时，请稍等片刻后重新打开 App。

共享账本没有更新

  1. 确认双方都已更新到最新版攒记，并正常登录 iCloud；
  2. 在“共享”页面确认邀请已经接受、账本仍处于共享状态；
  3. 在共享页或对应的记账本、攒目标页面下拉刷新；
  4. 只有账本创建者可以邀请新成员或停止共享。

设置快捷记支出

  1. 在攒记“设置 → 自动化”中安装半自动或全自动快捷指令；
  2. 打开系统“设置 → 辅助功能 → 触控 → 轻点背面”；
  3. 为“轻点两下”选择刚安装的攒记快捷指令；
  4. 在付款成功页或账单详情页轻点手机背面两下。

半自动模式会在保存前让你确认，识别结果更容易检查；全自动模式会直接保存，请定期核对金额和分类。

文字识别金额不准确

页面同时出现优惠券、红包或商品价格时，系统 OCR 可能提取多个金额。建议在付款成功页或账单详情页触发快捷指令， 并优先使用半自动模式确认最终付款金额。攒记不会在后台自行查看屏幕。

导出或删除数据

在“设置 → 数据管理”中可以导出 CSV 或 JSON，也可以清空本机和可同步的数据。 删除前请先完成需要的导出。仅卸载 App 不一定会删除保存在 iCloud 中的数据。

iCloud data is not syncing

  1. Make sure the devices use the same Apple Account and iCloud Drive is enabled;
  2. In Settings → Apple Account → iCloud, confirm that SavingNotes can use iCloud;
  3. Stay connected to the internet and pull to refresh on the Ledger or Goals tab;
  4. For a first sync or a larger data set, wait briefly and reopen the app.

A shared ledger is not updating

  1. Make sure everyone is using the latest SavingNotes version and is signed in to iCloud;
  2. On the Shared tab, confirm that the invitation was accepted and sharing is still active;
  3. Pull to refresh on the Shared tab or the related Ledger and Goals tabs;
  4. Only the ledger owner can invite additional members or stop sharing.

Set up Quick Recording

  1. In SavingNotes, open Settings → Automation and install the semi-automatic or fully automatic Shortcut;
  2. Open iOS Settings → Accessibility → Touch → Back Tap;
  3. Assign the installed SavingNotes Shortcut to Double Tap;
  4. Double-tap the back of the phone on a payment confirmation or transaction details page.

Semi-automatic mode lets you review a record before saving. Fully automatic mode saves immediately, so review amounts and categories regularly.

The recognized amount is inaccurate

Pages containing coupons, rewards, or product prices may produce several OCR amounts. Run the Shortcut on a payment confirmation or transaction details page and use semi-automatic mode when you want to verify the final paid amount. SavingNotes does not independently view your screen in the background.

Export or erase data

Open Settings → Data Management to export CSV or JSON files or erase local and syncable data. Export anything you need first. Uninstalling the app alone may not remove data stored in iCloud.
